1. What is AngularJS and why is it used?
AngularJS is an open-source JavaScript framework developed by Google for building dynamic Single Page Applications (SPAs). It extends HTML with additional features such as data binding, directives, and dependency injection, making web applications faster, structured, and easier to maintain.
2. Explain the MVC architecture in AngularJS.
MVC stands for Model, View, and Controller. In AngularJS, the Model represents application data, the View is the user interface written in HTML, and the Controller controls the interaction between Model and View. AngularJS follows a modified MVC approach closer to MVVM, where data binding keeps the model and view synchronized automatically.
